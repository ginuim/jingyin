# 镜隐移动端高保真 HTML Demo 设计

日期：2026-07-31  
状态：已批准（对话确认）  
输出目录：`./jingyin-mobile-demo/`

## 目标

基于 `jingyin-mobile` 线框原型，交付一套可点击的高保真移动端 HTML Demo，用于演示与评审。不做真实视频处理。

## 范围

### 包含（9 屏）

| 屏 | hash | 说明 |
|---|---|---|
| 首页 | `#home` | Hero、信任条、选视频入口、了解更多 |
| 选择视频 | `#upload` | 上传区 + 格式说明 |
| 编辑预览 | `#editor` | 预览、遮盖范围、设置入口、开始处理 |
| 效果设置 | `#settings` | 精度 / 模糊 / 声音（合并通用设置） |
| 导出中 | `#exporting` | 进度、停止、演示跳完成 |
| 导出完成 | `#export-done` | 结果预览、保存、回首页/继续编辑 |
| 适用场景 | `#scenarios` | 四张场景卡 |
| 使用步骤 | `#how` | 三步说明 |
| 隐私政策 | `#privacy` | 摘要 + 要点 |

### 动线

- 主路径：`home → upload → editor → settings → exporting → export-done`
- 旁路：`home ↔ scenarios / how / privacy`
- 文案沿用 `jingyin-mobile` 原型

### 不做

- 真实文件选择、Vision、编码、StoreKit
- 主体选择 / 高精说明子页
- 深色主题切换
- npm 构建链路

## 技术方案

**方案：单页 SPA（已选）**

- `index.html` + `styles.css` + `app.js` + `README.md`
- `location.hash` 路由；默认 `#home`
- 手机框固定约 375×812，桌面居中；壳外提供页面索引便于跳屏
- 纯静态，双击或本地静态服务即可打开

备选已否决：多文件 HTML（跳转弱）、画板同屏（演示弱）。

## 视觉系统

独立演示风，不强制对齐现站 CSS。

- 背景冷灰雾 `#E8ECF0`；页内近白 `#F4F6F8`
- 主文字墨青 `#0F1B24`；次要 `#5A6A76`
- 强调雾青 `#2A6F7A`；边框 `#D0D7DE`；信任徽章底 `#DCE8EA`
- 标题 `Fraunces`；正文/UI `Manrope`
- 卡片圆角 16px，按钮 12px，手机框 36px
- 切屏 150ms fade + 轻上移；`prefers-reduced-motion` 关闭位移
- 媒体区用灰底占位标签，无外链图

避开：紫渐变、暖奶油衬底、默认深色主题。

## 交互约定

- 设置页点选只改 UI 选中态
- 上传「选择视频」直接进编辑（假数据）
- 导出中可「跳到完成」；「停止」回编辑
- 主 CTA 满宽雾青；次按钮描边

## 验收

- 主路径点通
- 旁路三页可回首页
- 手机宽度可读；桌面显示手机框
- 无需联网依赖（字体可用系统回退）
