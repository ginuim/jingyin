# 视频编辑工作区开发计划：工具切换方案

日期：2026-09-08；2026-09-09 更新：核心视频工作区已实现，完整回归与真机验收进行中。见 [实施与验证记录](./ios-video-refactor-validation-2026-09-09.md)。

## 1. 已确认的方向与文档关系

用户在比较垂直平铺、工具切换、三步骤概念图后选择了**工具切换方向**，要求先形成开发计划，后续在新任务实施。本轮只新增计划与保存设计素材，不修改 App 代码、不创建新任务。

产品与发布依据仍为 [iOS 首发方案](./ios-app-plan.md)、[首发 TODO](./ios-launch-todo.md)。问题依据是 [2026-09-08 UX 审查](./ios-ux-audit-2026-09-08.md)，视觉约定参考 [设计规范](./ios-design-guidelines.md)。本文确定视频改造的执行顺序与建议交互细节；后续用户调整优先于本文。

**选择的是同一编辑工作区内切换工具，不是全局 Tab 导航，也不是必须依次完成的 1、2、3 向导。** 用户可以反复在对象、效果、声音和补遮之间切换。整体流程仍为：导入 → 编辑与检查 → 处理设置 → 处理/结果 → 保存或分享。

## 2. 本次开发范围

### 完整目标

1. 固定视频预览、可见时间轴、四个工具入口及唯一“下一步”。
2. 四个面板：遮盖对象、画面效果、声音、手动补遮；每次只显示当前面板。
3. 对象与画面选中关系清楚，手动补遮的位置/显示时间行为可解释。
4. 主编辑器与全屏调整共用编辑状态和操作；进入全屏不依赖某张卡片是否展开。
5. 显示准确的本次导出摘要；保留现有付费限制、性能边界与清理行为。
6. 四语、深浅色、大字体及横竖素材验证。

### 本次不扩展

- 首页重排、照片复核状态机、照片免费导出提示、照片结果裁切和 Paywall 全面改造：仍是审查中的待办，另开工作包，不混进本次视频改造。
- 不新增自动身份跟踪、指定人脸持续跟随、车辆识别、视频手绘、长 vlog、4K/HDR、后台处理或恢复工程。
- 不改价格、权益来源或免费视频 30 秒/720p、照片单张限制。
- 不重新实现视频处理器或将模型推理搬到 UI。
- 普通画布缩放/平移、缩略时间轴双指缩放等高级交互可后续扩展；本计划先保证完整适配、全屏调整与准确寻帧。

## 3. 页面布局契约

默认竖屏工作区：

```text
返回                  视频遮盖                 更多

                  完整素材预览
            按当前工具显示选中框/编号

播放   00:08 / 00:24                         放大查看
缩略帧时间轴 ───────── 播放头 ───────────────────

遮盖对象       画面效果       声音       手动补遮

                  当前工具面板
           可在面板内部滚动，不滚走画布

            人物 · 像素化 · 原声
                    下一步
```

- 默认使用底部安全区固定的全宽“下一步”；顶部不再重复放主动作。按钮打开处理设置，不直接导出。
- 顶部“更多”只收纳低频操作；没有实际低频项时不必强行增加。
- 四个工具均有可见文字、选中状态和 VoiceOver 标签，不能只有图标。
- 摘要从真实 `ProcessingOptions` 推导；是低强调的一行文字，不再增加一张大的权益/配置卡片。
- 常规字号下，工具切换不改变画布和时间轴位置。面板以统一可用区域承载；复杂内容可内部滚动，或显式展开参数面板。
- 不照搬照片页固定 160pt 面板：以安全区、可用高度和动态字体测量布局。先为导航、播放、工具和主动作预留空间，再分配画布/参数区。
- 横向素材按显示方向完整 aspect-fit；竖素材增加可用画布高度但保留操作入口，不裁切源图去迎合概念图。
- 极大字体/紧凑高度允许明确的展开面板或适配布局，不能通过缩小关键信息、遮住“下一步”来凑屏。非必要时不自动跳成另一导航结构。
- 去掉预览上的常驻橙色图钉：主布局本身固定预览，不再需要用户自行管理钉住/取消固定。
- 使用 `AppPalette`、共享 ButtonStyle 和动态字体；工具图标以既有 18pt 档为起点，触摸区域至少 44×44pt。

## 4. 工具面板与现有能力映射

### 4.1 遮盖对象

默认首次进入该面板，但实际选项读取已有视频偏好。目前 `ProcessingOptions` 默认人物，本次保留，不自动切换为人脸。

常用目的入口可以用四个选项，写入同一个 `ProcessingOptions`，不要维护第二套互相漂移的配置：

| 入口 | 明确操作后的配置 | 补充规则 |
| --- | --- | --- |
| 人脸 | `scope = .subjects`、`subjects = [.face]` | 主体选择按用户这次明确点击更新 |
| 整个人 | `scope = .subjects`、`subjects = [.person]` | 不同时选人物与人脸，沿用已有互斥规则 |
| 背景 | `scope = .background` | 展示“保留什么”，使用现有主体选择；不要将已有猫狗组合悄悄清掉 |
| 全画面 | `scope = .full` | 隐藏对象编辑框、暂时禁用补遮；保留既有轨道，切回恢复 |

另有“更多对象”支持猫狗及当前有效组合；从现有偏好进入人脸＋猫狗等组合时，摘要显示真实组合，不能错误点亮“仅人脸”。如当前组合不对应四个预设，显示“自定义”摘要。

必须为只做手动补遮保留可理解入口，如“自动识别：关闭”，映射到当前允许的空主体集合；不能强迫用户通过反复取消所有复选框来发现。背景模式没有有效保留对象时需说明并引导选择，不能悄悄输出意外的全画面结果。

自动分析中、当前帧未检测到、失败、已有结果分别显示简短真实状态。避免“全部隐私已保护”或默认完成勾号。

### 4.2 画面效果

保留像素化、视觉模糊、ASCII、条件允许时的贴纸。正常面板不重复显示处理精度。

- 像素化：默认推荐，保留真实强度/块大小表达，不用概念图中的任意百分比替代。
- 模糊：明确是视觉模糊，不宣称隐私保障。
- ASCII：颜色主题、自定义颜色、近期颜色等现有能力继续可达。
- 贴纸：仅遮盖主体且仅人脸时可用，大小而非强度；继续复用 `supportsFaceSticker` 和原有自动回退规则。
- 工具切换不触发效果重置；只有用户改变效果类型时才沿用当前有意设计的默认强度切换。

### 4.3 声音

保留原声、静音、变音。变音时显示音调调整与试听状态；未选变音不展示相关说明和控件。

切换工具保留音调、播放位置和设置。用现有 `VoicePreviewEngine` 管理声音，不创建第二个播放器；不能让声音变化无故重建视觉推理任务。

### 4.4 手动补遮

面板显示：添加区域、当前区域选择、显示时段、位置行为、删除/撤销。添加入口用文字明确选择椭圆或矩形；本次不新增视频手绘。

- 选中手动区域才显示它的工具；空状态显示“添加一个区域，遮住遗漏内容”。
- 进入工具自动暂停播放，方便操作；切换到其他工具保留区域和选中 ID，但隐藏手柄。隐藏手柄不能让真实遮盖效果消失。
- 全画面模式显示“不需要单独补遮”的说明，不删现有区域。
- 背景模式的手动区域沿用当前合成语义，实施前读取处理器确认究竟保留还是遮盖该区域，并使用准确的上下文文案；不能默认主体模式的含义与背景完全一致。
- 垃圾桶删除当前整条轨道；空白处取消选中；右上角 X 不再承担删除。

## 5. 编辑状态与操作契约

### UI 状态与处理状态分开

- 工具选择（例如 `VideoEditorTool`）、面板展开、选中 ID 是会话 UI 状态。
- `ProcessingOptions`、`MaskTrack` 是处理真相；不得复制到每个 Tab 的独立 `@State` 后仅靠切换时同步。
- 同一 `AVPlayer`、播放位置和已有预览任务贯穿工具切换。纯切换工具不能写入关键帧、改变效果、重置偏好、重新分析视频。
- 退出处理设置返回编辑时保留当前工具、时间和选中区域；从结果返回编辑沿用已有项目生命周期。
- 普通工具之间切换保持播放行为；进入补遮或拖动时间轴时暂停。离开补遮不自动恢复播放，避免用户操作时画面突然移动。
- 当前帧对象不存在时清理失效高亮，显示“当前画面未找到该对象”；不把旧坐标绘到另一个人身上。

### 对象高亮

首轮使用已有 `MaskEntity` 当前矩形与 ID 画框/编号，列表选中和画面点选互通，不引入人物裁切缩略图或新识别数据存储。

只有“遮盖对象”工具接收自动对象点选，“手动补遮”只接收手动区域操作；解决重叠命中优先级，避免一个点击同时切换两类对象。编号是当前画面定位提示，不是稳定人物身份承诺。

提示用“取消遮盖此对象”，但必须核对现有排除逻辑在后续帧中的实际范围；不把一次选择包装成可靠跨镜头身份追踪。原本隐藏的 `FaceSelectionView`/跟踪原型保持隐藏。

## 6. 时间轴规格

时间轴是本次完整目标的一部分，不止在图里画出来。

- 显示当前位置、总时长、播放/暂停、可拖动播放头、等间隔取样缩略帧。
- 时间到位置线性映射正确，例如 24 秒视频的 8 秒在全长约三分之一，不能复制生成图中居中的 8 秒播放头。
- 保留并区分当前区域的生效时段与位置记录点；在补遮面板提供上一记录/下一记录，当前时间使用足够精度。
- 继续复用 `ControlledVideoPlayer` 已有 seek、暂停、时间观察和 marker/range 数据；先定位实现，再决定是否提取独立 timeline 视图。
- 缩略帧后台按需生成，应用 preferredTransform，设置尺寸和数量上限；只生成当前显示所需的少量全帧，不对每个视频帧推理，不提取人脸裁切。
- 首屏先显示可用的时间控件，缩略图逐步填充；失败回退普通时间轴，不能阻断播放或导出。
- 缓存仅限当前会话内存；离开、换素材、任务取消时释放并取消生成，不写 UserDefaults/磁盘、不联网。跨素材的异步回调必须校验任务身份。
- 新增帧派生/缓存前按仓库人脸数据规则审核：若改变现有隐私政策中描述的派生、保留或删除方式，必须在同一变更同步四语政策、审核说明和相关文档。不能因为“只是 UI 缩略图”而跳过核对。
- 默认不放“已遮盖”暗示的缩略图状态；若缩略图来自原素材，应保持语义中立，实际遮盖结果以当前预览/输出为准。
- 记录缩略图开关前后的首屏时间与内存，避免为了显示时间轴拖慢本地处理。

## 7. 手动区域的时间行为：独立工作包

这是行为改变，必须在页面结构稳定后单独实施和测试。阶段一可以保留原逻辑，但不能提前显示尚未实现的“固定位置”开关。

### 完整目标的规则

| 操作 | 行为 |
| --- | --- |
| 新建手动区域 | 默认固定位置、整段视频，明确不会自动跟随 |
| 固定位置下拖动/缩放 | 更新整个生效时段内的同一矩形，不因播放头位置生成运动 |
| 开启随时间调整 | 保留当前矩形作为初始位置，显式记录基准时间；后续拖动写入当前时间 |
| 随时间调整下拖动/缩放结束 | 一次手势对应一次可撤销编辑，自动记录并反馈“已记录 00:03.2 的位置” |
| 两个位置记录之间 | 沿用 `MaskTrack` 现有插值，解释为“在记录位置之间移动”，不宣称追踪对象 |
| 第一条之前/最后一条之后 | 在有效时段内沿用首/末位置，具体行为对照现有 `rect(at:)` 验证 |
| 改回固定位置 | 采用当前显示位置，明确其他位置变化将被移除；确认或完整撤销保护 |
| 改显示时间 | 只改变 `activeFromSeconds/activeUntilSeconds`，不顺带制造位移记录 |
| 删除位置记录 | 保留有效轨道，最后一个不能删成不可见的无效状态；提供清楚的禁用原因 |

“在此时刻保持当前位置”作为高级命令保留，用于安排移动起点；不把手动记录作为每次拖动后的必需动作。

### 实现要求

- 优先复用现有轨道与矩形模型，增加最小必要的手动位置模式，不重写渲染器。
- 若增加 Codable 字段，旧数据缺字段必须兼容：多位置记录保留为随时间调整；单记录可以视为固定；不迁移/改写隐藏的自动跟踪轨道。
- 撤销只保存当前会话必要的区域/时间/选择状态，按一次拖动结束合并，不保存每个拖动采样或媒体副本。至少覆盖新增、删除、移动、缩放、时段、模式切换和位置记录。
- 主编辑器与全屏使用同一组动作与撤销源；操作不能在其中一个入口成功、另一个入口静默失效。
- 不新增持久化编辑工程、人物身份或磁盘历史。本项目当前不承诺工程恢复。

## 8. 全屏工作区

- 放大预览可从播放器进入；“手动补遮 → 放大调整”进入可编辑工作区，编辑能力不取决于主面板是否曾展开。
- 全屏有明确“完成”，共享当前播放头、区域、位置模式、时段和撤销状态；退出不丢修改。
- 常用工具可见：区域选择、添加、显示时段、位置行为；高级记录与删除进更多菜单，避免一长串没有滚动提示的小按钮。
- 正常竖屏提供完整素材适配与合理工具布局。横屏支持先检查工程方向策略，不能仅为“更大”擅自扩大整个 App 的设备方向支持；若工程支持横屏则必须做安全区和坐标验证。
- 主编辑器与全屏均由 `VideoCoordinateSpace` 明确处理画布边距和 aspect-fit 范围。不能用拉伸视频解决留黑问题。

## 9. 处理设置与结果衔接

- 编辑页按钮：“下一步”；设置确认：“开始处理”。
- 免费本次时长使用 `min(素材时长, 30 秒)`，分辨率采用实际有效上限；超过限制才说明“仅前 30 秒”。短片不能固定显示“免费处理 30 秒”。
- 摘要包括实际时长、有效分辨率、声音。仍允许免费完整编辑预览。
- 处理精度继续位于设置页；全画面模式按现有规则隐藏不相关精度项。
- 保留真实 StoreKit 本地化价格、购买入口和降级提示；不要用 Debug 参数证明生产权益。
- 处理/结果一体页继续使用实际帧预览、系统进度、固定取消与已有清理逻辑；本次不重做其视觉系统。

## 11. 分阶段任务与完成标准

按依赖顺序完成，一个阶段一个可审查差异。新任务默认完成全部视频工作包 A–F，不能只做壳就宣称完整改造完成；若用户只要求某阶段，则按明确范围交付。

## 13. 风险与处理原则

- **工具栏切换导致视图重建**：播放器与处理状态保留在宿主，面板只绑定，不为每个工具创建独立播放器。
- **主体与画面异步错位**：标注使用与当前预览对应的快照/时间；过时结果不显示成当前选中对象。先解决对应，再谈精致动画。
- **更多功能在概念图里缺失**：能力清单是验收依据，不能删 ASCII 或猫狗来凑四个按钮。
- **时间行为改变已有输出**：布局和模型分开提交，兼容旧轨道并对照预览/导出；阶段 B 不使用未实现模式的文案。
- **字号压缩以适配图片**：按真实点尺寸、动态字体和安全区实现，生成图不能覆盖系统可用性要求。
- **共享组件波及照片**：保持照片原有行为，只调整必要接口；照片重构留在独立工作包。
- **产品文档已有矛盾**：审查记录了贴纸状态、照片免费单张重复勾选等差异；核对后同步说明，不据旧段落撤掉已经存在的功能。

- [ ] 验证失败后重试、取消后重新处理，以及处理中返回编辑；旧进度/旧结果不能覆盖新任务。

- [ ] 测量首个响应帧、拖动期间延迟和松手到最终帧耗时，并记录设备、素材、识别类型和处理精度。至少保留一段屏幕录制，不仅拍松手后的截图。
