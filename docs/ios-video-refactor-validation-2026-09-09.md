# 视频重构实施与验证记录

2026-09-09。核心工作区已实现，完整发布验收尚未结束。

## 已实现

- 四工具与单参数面板、固定下一步、参数展开、共享全屏手动控制。
- 删除重复的人脸/人物快捷项；保留范围、自动识别开关、人物/人脸/猫狗及允许组合，ASCII 与贴纸、声音选项。
- 画布完整适配、紧凑间距与圆角，工具切换不改变输出配置。
- 当前帧对象编号与点选；过期检测框隐藏，返回同一帧复用快照，不宣称跨镜头身份保持。
- 最多八张会话缩略帧、线性时间位置、失败回退、会话清理。
- 固定/随时间模式、整段或指定时段、前后位置定位、会话撤销；时段变化不添加关键帧。全屏共享操作。
- 连续寻帧采用在途请求合并，最新目标最终落地；预览强制更新当前帧检测，避免跳转复用旧蒙版。
- 四语文案与缩略图/撤销数据的四语隐私政策源码和审核说明草稿。

### 2026-09-09 视频 P0 生命周期收尾

- 为每次视频处理增加独立运行代次；旧任务取消、失败或进度回调不能覆盖新任务，旧预览回调也不能写入当前运行。
- `AVAssetExportSession`、变音音轨提取和合成均接入 Swift 任务取消；变音临时音频在失败或取消时清理。
- 处理完成与取消确认弹窗竞争时以完成为唯一终态：完成会自动关闭旧弹窗并进入结果页，不能再从旧弹窗丢弃有效结果。
- Debug 增加一次性失败、运行中重启和延迟取消注入；视频编辑页的自动处理钩子改为每次导入仅执行一次，避免取消返回后再次自动处理。
- iPhone 16 / iOS 18.1 模拟器实测：180 秒处理中延迟取消后返回编辑，10 秒失败注入后自动重试成功，180 秒处理中启动新运行后完成；取消与重启路径均无 `jingyin-chunk-*` 遗留，结果页仅保留当前成品。
- Debug 与 Release 模拟器构建通过；`MaskTrackValidation` 增补预览/Core Image 坐标、Vision 往返并通过。
- iPhone SE（第 3 代）/ iOS 18.1、深色、英文、Accessibility Large 与 Accessibility XXXL 走查后修复工具名和时间标签截断；无障碍字号改为 2×2 工具栏、独立时间摘要，并将复核提醒移入可滚动参数区，底部“下一步”保持可见。其余三语和 VoiceOver 仍待完整矩阵。
